# 📶 Wi-Fi QR Generator

**Генератор QR-кодов для быстрого подключения к Wi-Fi — прямо в браузере.**

Один HTML-файл. Ввёл имя сети и пароль — получил QR-код, который телефон распознаёт как предложение подключиться к Wi-Fi. Скачивание в PNG и SVG, печать, копирование payload, генератор паролей, светлая и тёмная темы, русский и английский языки. Никаких бэкендов, отправки данных и регистрации.

---

## 🎮 Возможности

- **Генерация Wi-Fi QR-кода** — стандартный формат `WIFI:S:<SSID>;T:<TYPE>;P:<PASSWORD>;H:<HIDDEN>;;`, который понимают Android и iOS.
- **Три типа шифрования:**
  - 🔒 WPA / WPA2 / WPA3 (по умолчанию)
  - 🔓 WEP
  - 🚪 Без пароля (`nopass`)
- **Скрытая сеть** — чекбокс добавляет `H:true` в payload.
- **Корректное экранирование** — спецсимволы `\ ; , " :` в SSID и пароле экранируются по стандарту, поэтому сети вроде `My;WiFi` или `Pa:ss:word` работают корректно.
- **Генератор паролей** — 16 символов из `A-Z a-z 0-9`, через `crypto.getRandomValues` с фолбэком на `Math.random`.
- **Копирование пароля** — кнопка `📋` рядом с полем пароля.
- **Копирование payload** — кнопка `📋 Payload` копирует «сырую» строку `WIFI:...` в буфер обмена.
- **Скачивание PNG** — рендер QR на `<canvas>` с масштабом 12x, имя файла берётся из SSID.
- **Скачивание SVG** — векторный QR, идеально масштабируется без потерь.
- **Печать** — `window.print()` с отдельными `@media print` правилами: остаётся только сам QR-код, без интерфейса. Удобно распечатать и повесить на стену.
- **Живое обновление** — QR пересчитывается по мере ввода с дебаунсом 80 мс.
- **Просмотр payload** — сворачиваемый `<details>` с «сырой» строкой для отладки.
- **Тёмная и светлая темы** — через CSS Custom Properties на `<body class="dark">`, с автоопределением системной темы и сохранением выбора в `localStorage`.
- **Два языка интерфейса** — Русский и English, переключаются мгновенно, выбор сохраняется.
- **Предупреждение о сканировании** — важная подсказка наверху: сканировать нужно **в приложении «Камера»**, а не из меню настроек Wi-Fi, иначе код не распознаётся.
- **Адаптивная вёрстка** — одна колонка, `max-width: 480px`, отлично смотрится на телефоне и десктопе.

## 🚀 Быстрый старт

### Вариант 1 — просто открыть

```
git clone <репозиторий>
cd wifi-qr-generator
```

Открой `index.html` двойным кликом в браузере.

> ⚠️ Копирование через `navigator.clipboard` работает только в защищённом контексте (`https://` или `localhost`). Скачивание PNG/SVG и печать работают везде.

### Вариант 2 — локальный сервер (рекомендуется)

```bash
# Python 3
python -m http.server 8000

# или Node.js
npx serve .
```

Затем открой [http://localhost:8000](http://localhost:8000).

## 🕹️ Как пользоваться

1. Введи **имя сети (SSID)** — точно такое же, как в роутере. Регистр и символы важны!
2. Введи **пароль** (или нажми `🎲`, чтобы сгенерировать).
3. Выбери **тип шифрования** — WPA/WPA2/WPA3 для современных сетей, WEP для legacy, «Без пароля» для открытых сетей.
4. При необходимости отметь **«Скрытая сеть»**, если SSID не вещается в эфир.
5. QR-код обновится автоматически.
6. Отсканируй его **приложением «Камера»** (iOS) или **Google Lens / Камерой** (Android) — появится уведомление «Подключиться к сети», тапни его.
7. При желании — скачай PNG/SVG или распечатай на принтере.

### Важно о сканировании

> ⚠️ **Не пытайтесь сканировать QR из меню настроек Wi-Fi.** Большинство Android-устройств не умеют импортировать Wi-Fi конфигурацию из меню настроек — QR нужно сканировать через камеру (Google Lens, Camera app, или стороннее приложение), иначе система не покажет уведомление «Подключиться».

## 📐 Формат payload

Стандарт Wi-Fi QR — строка вида:

```
WIFI:S:<SSID>;T:<TYPE>;P:<PASSWORD>;H:<HIDDEN>;;
```

| Поле | Значение |
|------|---------|
| `S` | SSID (имя сети) |
| `T` | Тип шифрования: `WPA`, `WEP` или `nopass` |
| `P` | Пароль (для `nopass` — не указывается) |
| `H` | `true` если сеть скрытая, иначе `false` |
| `;;` | Обязательный двойной `;` в конце |

**Пример:**

```
WIFI:S:MyHomeWiFi;T:WPA;P:SuperSecret123;H:false;;
```

### Экранирование

Символы `\ ; , " :` в SSID и пароле экранируются обратным слешем:

```
SSID: My;WiFi     → S:My\;WiFi
Pass: Pa:ss:word  → P:Pa\:ss\:word
```

## 🐛 Известные особенности

- **iOS:** QR-код Wi-Fi распознаётся системной камерой начиная с iOS 11. Однако встроенная камера показывает только предупреждение «Открыть в настройках» — не пугайся, это нормально.
- **Android:** сканируй именно через **Google Lens** или **Camera app**, а не через настройки Wi-Fi. Иначе система просто покажет текст `WIFI:...` и не предложит подключиться.
- **`navigator.clipboard`** работает только в защищённом контексте. При открытии через `file://` кнопки копирования выведут `alert` с payload — его можно скопировать вручную.
- **Скачивание файлов** работает и через `file://`, и через `http://localhost`.
- **Печать** — через `window.print()`. В режиме печати скрывается весь интерфейс, остаётся только QR-код на белом фоне.
- **Спецсимволы** в SSID (например, эмодзи или кириллица) поддерживаются благодаря `UTF-8` и `Byte`-режиму кодирования QR.

## 🔒 Безопасность и приватность

- **Никаких серверов** — весь расчёт происходит локально в браузере.
- **Никаких запросов** — данные не отправляются никуда, кроме загрузки библиотеки QR с CDN при первой загрузке страницы.
- **Никаких трекеров** — реклама, аналитика и куки отсутствуют.
- **Пароль не сохраняется** в `localStorage` и не передаётся между сессиями — только язык и тема.
- **В QR-коде пароль хранится в открытом виде** (так устроен стандарт Wi-Fi QR). Генерируй QR только в безопасном месте и не публикуй скриншоты с реальным паролем.
